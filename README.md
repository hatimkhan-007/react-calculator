# 🧮 React Calculator

A simple and modern **Calculator Web App** built with **React.js**.
This project was created to practice React fundamentals, especially **components, state management, event handling, and conditional logic**.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input
* 🔘 Decimal numbers
* 🧹 Clear button
* 🟰 Calculate results
* 📱 Responsive design
* 🎨 Modern dark-themed UI
* ⚡ Interactive button effects

## 🛠️ Technologies Used

* **React.js**
* **JavaScript (ES6+)**
* **CSS3**
* **Vite**
* **HTML5**

## 📚 React Concepts Practiced

This project helped me practice:

* React components

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/react-calculator.git
```

Go into the project directory:

```bash
cd react-calculator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.
